### Thème 1:
Avant toute choses il faut allez dans le terminal de visual code, appuyez sur terminal puis "new terminal" et mettez les information ci-dessous:
```
git init 
git config user.name "nom"
git config user.email "mail@mail.com"
```
1. En premier alez sur [gitHUB.com](https://github.com/) et crée un compte si vous n'en avez pas sinon connecter vous avec votre compte existant

2. Allez sur votre fichier ou dossier visual code et appuyer sur le 3ème onglet sur la gauche et appuyez sur initialize repisotory, ensuite appuyer sur le petit nuage qui ce trouveras dans l'onglet "graph"  
![image-aide](image-graph.png)   ![image-aide](image-nuage.png)

3. Ensuite git vous demanderas de vous reconnecter avec votre compte et tout sera bon après ceci

Ensuite vous pouvez retoutrner sur votre projet,vous pouvez ensuite reouvrir le 3ème onglet a gauche et retourner sur graph,puis a chaque fois vous appuyerez sur le "push" vous updaterez votre projet qui se trouve sur github.Push ce trouver dans l'onglet graph.(Le push c'est la flèche qui pointe vers le haut)
