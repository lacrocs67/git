### Thème 3:

### Les commandes Git et leurs définitions

1. **git init** : Permet de commencer à suivre un projet avec Git. C'est comme créer un carnet pour garder l'historique de son travail.

2. **git clone** : Permet de copier un projet existant depuis GitHub ou GitLab sur son ordinateur.

3. **git add** : Permet de préparer les fichiers modifiés avant de les enregistrer.

4. **git commit** : Permet d'enregistrer les modifications dans l'historique du projet avec un message explicatif.

5. **git push** : Permet d'envoyer ses modifications enregistrées vers un dépôt distant comme GitHub.

6. **git branch** : Permet de créer ou de regarder des branches pour travailler sur différentes fonctionnalités sans toucher directement au code principal.

7. **git fetch** : Permet de récupérer les nouveautés du dépôt distant sans les intégrer directement à sa branche actuelle.

8. **git rebase** : Permet de replacer ses commits sur une autre base pour garder un historique plus linéaire.

9. **git merge** : Permet de réunir les modifications de deux branches dans une seule.

10. **git pull** : Permet de récupérer les nouveautés du dépôt distant et de les intégrer à sa branche actuelle.
